# Myocard Labs — brand assets

Logo: a heart with an intracardiac-EGM waveform — a teal→indigo gradient with a coral signal.

## Files
- `myocard_icon.svg` — primary mark (vector, transparent). Use this for the GitHub org avatar.
- `myocard_icon_1024.png`, `myocard_icon_512.png` — raster, transparent background.
- `myocard_badge_white.svg` / `_1024.png` / `_512.png` — circular seal, **white** lettering; ideal as the GitHub org avatar.
- `myocard_badge_coral.svg` / `_1024.png` / `_512.png` — circular seal, **coral** lettering (matches the ECG signal).
- `myocard_wordmark.svg` / `.png` — horizontal lockup (icon + "Myocard Labs") for light backgrounds.
- `myocard_wordmark_ondark.svg` / `.png` — lockup for dark backgrounds (light text; PNG shown on a dark tile).

## Palette
| Role | Hex |

| Gradient — indigo | `#3A46C0` |
